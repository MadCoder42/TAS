API keys

Keys are tried from top to bottom. When one hits its usage limit (error 429), the next one takes over until the first recovers. Keys are encrypted (AES-256-GCM) before they are saved and are only decrypted for the instant a request is sent, so they are never shown again after you add them. They go nowhere except Google's Gemini API.

    Get a free key at aistudio.google.com/apikey.
